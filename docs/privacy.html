隐私政策

生效日期：2026年2月11日

核心承诺：BrowseBuddy 是一款完全本地运行的浏览器扩展。我们不收集、不存储、不传输任何您的个人数据或浏览信息。

🔒 隐私政策

生效日期：2026年2月11日

1. 我们收集的信息

我们不收集任何信息。

BrowseBuddy 的所有功能都在您的浏览器本地运行，包括：

  • 历史记录读取与分析
  • 黑名单匹配与自动删除
  • 统计数据生成
  • 用户设置保存

2. 数据存储

所有数据都使用浏览器提供的本地存储 API 保存在您的设备上：

2.1 存储位置

  • 插件设置：使用 chrome.storage.local 存储在浏览器本地
  • 黑名单与收藏：使用 chrome.storage.local 存储在浏览器本地
  • 停留时长统计：使用 chrome.storage.local 存储在浏览器本地
  • 备份数据：使用 chrome.storage.local 存储在浏览器本地
  • 历史记录：仅读取浏览器内置历史数据，不做额外存储
  • 导出文件：仅在您主动导出时保存到您选择的位置

2.2 存储限制

浏览器本地存储通常限制在 5-10MB，这足以存储数千条黑名单记录和插件设置，但无法存储大量历史记录副本（这是有意设计，确保数据始终留在浏览器中）。

3. 数据使用

您的数据仅用于以下用途：

  • 显示您的历史记录列表和统计信息
  • 根据黑名单自动删除特定历史条目
  • 保存您的插件偏好设置

4. 数据共享

我们不会与任何第三方共享您的数据。

原因是我们根本无从获取您的数据——所有处理都在本地完成，没有服务器端组件，没有数据传输。

5. 权限使用说明

BrowseBuddy 请求的每个权限都有明确用途：

  • history：读取和删除浏览器历史记录（核心功能）
  • storage：保存插件设置、黑名单、收藏和停留时长（本地存储）
  • tabs：读取标签页 URL（添加当前页面到黑名单、实时黑名单保护）
  • sessions：恢复最近关闭的标签页或窗口
  • alarms：定时任务（自动备份、自动清理、停留时长快照）
  • contextMenus：添加右键菜单项，快速将网站加入黑名单

6. 安全措施

  • 所有代码在浏览器沙箱环境中运行
  • 不执行任何网络请求（除扩展商店更新检查）
  • 不注入任何脚本到网页
  • 开源代码可供安全审查

7. 您的权利

您完全掌控自己的数据：

  • 随时导出黑名单数据
  • 随时清除所有插件数据（通过浏览器扩展管理）
  • 随时卸载扩展，所有相关数据将被自动清除

8. 隐私政策更新

我们可能不时更新本隐私政策。任何重大变更将通过扩展更新说明或网站公告通知用户。

Privacy Policy

Effective Date: February 11, 2026

Core Commitment: BrowseBuddy is a purely local browser extension. We do not collect, store, or transmit any of your personal data or browsing information.

🔒 Privacy Policy

Effective Date: February 11, 2026

1. Information We Collect

We do not collect any information.

All features of BrowseBuddy run locally in your browser, including but not limited to:

  • History record reading and analysis
  • Blacklist matching and automatic deletion
  • Statistics generation
  • User settings storage

2. Data Storage

All data is stored locally on your device using browser-provided storage APIs:

2.1 Storage Locations

  • Extension Settings: Stored in browser local storage using chrome.storage.local
  • Blacklist & Favorites: Stored in browser local storage using chrome.storage.local
  • Dwell Time Stats: Stored in browser local storage using chrome.storage.local
  • Backup Data: Stored in browser local storage using chrome.storage.local
  • History Records: Only reads built-in browser history, no additional storage
  • Exported Files: Saved only to user-selected locations when actively exported

2.2 Storage Limitations

Browser local storage is typically limited to 5-10MB, which is sufficient to store thousands of blacklist entries and settings, but cannot store large history copies (this is intentional design to ensure data remains in the browser).

3. Data Usage

Your data is used solely for:

  • Displaying your history list and statistics
  • Automatically deleting specific history entries based on blacklist
  • Saving your extension preferences

4. Data Sharing

We do not share your data with any third parties.

The reason is simple: we have no access to your data — all processing is done locally with no server-side components or data transmission.

5. Permission Usage

Each permission requested by BrowseBuddy has a specific purpose:

  • history: Read and delete browser history (core functionality)
  • storage: Save extension settings, blacklist, favorites and dwell time (local storage)
  • tabs: Read tab URLs (add current page to blacklist, real-time blacklist protection)
  • sessions: Restore recently closed tabs or windows
  • alarms: Scheduled tasks (auto-backup, auto-cleanup, dwell time snapshots)
  • contextMenus: Add right-click menu items to quickly blacklist websites

6. Security Measures

  • All code runs in browser sandbox environment
  • No network requests (except extension store update checks)
  • No scripts injected into web pages
  • Open source code available for security audit

7. Your Rights

You have full control over your data:

  • Export blacklist data at any time
  • Clear all extension data via browser extension management
  • Uninstall the extension at any time — all related data will be automatically cleared

8. Privacy Policy Updates

We may update this privacy policy from time to time. Any significant changes will be notified through extension update notes or website announcements.
