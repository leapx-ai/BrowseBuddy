BrowseBuddy

您的个人浏览器历史记录管理器

📋 产品介绍

BrowseBuddy 是一款专注于浏览器历史记录管理的增强型插件，提供专业级的历史记录管理功能，同时高度重视用户隐私保护。所有数据均在本地处理，绝不会上传至任何云端服务器。

🔐 核心隐私承诺

  • 所有数据仅存储在您的设备本地
  • 不会上传任何数据到云端服务器
  • 不会与第三方共享您的浏览历史
  • 代码开源透明，可审查

✨ 主要功能

智能删除

按日期、域名、关键词批量删除历史记录，支持预览确认

统计分析

可视化展示浏览习惯，包括热门网站、停留时长、访问时段分布等

隐私保护

智能黑名单自动删除敏感网站的历史记录，支持收藏保护与自动清理

日历视图

按日历查看每日访问量，快速跳转到特定日期

会话隐身

开启后本次浏览会话不留下任何历史痕迹

恢复标签页

一键恢复最近关闭的标签页或窗口

数据导出

支持导出 CSV 和 HTML 报告，便于备份和分析

多语言

支持中文和英文界面，可自由切换

🔑 权限说明

为了提供上述功能，BrowseBuddy 需要以下权限。我们遵循最小权限原则，仅请求功能所必需的权限：

权限 用途说明 是否必需
history 读取、管理和删除浏览器历史记录。这是插件的核心功能所需。 ✅ 必需
storage 本地存储插件设置、黑名单数据和用户偏好。所有数据均保存在本地。 ✅ 必需
tabs 读取标签页 URL，用于"添加当前页面到黑名单"和黑名单实时保护（访问敏感网站时自动删除历史）。 ✅ 必需
sessions 恢复最近关闭的标签页或窗口。 ✅ 必需
contextMenus 添加右键菜单项，允许用户快速将当前网站加入黑名单。 可选

📜 隐私政策

数据收集

BrowseBuddy 不收集任何个人数据。所有功能均在本地运行，包括但不限于：

  • 历史记录分析
  • 黑名单匹配
  • 统计数据生成
  • 用户设置存储

数据存储

所有数据均使用浏览器提供的本地存储 API（chrome.storage.local）保存，存储位置：

  • 插件设置：存储在浏览器本地存储空间
  • 黑名单数据：存储在浏览器本地存储空间
  • 导出文件：由用户选择保存位置

数据共享

我们不会与任何第三方共享您的数据，因为我们根本无从获取您的数据。
