BrowseBuddy

Your Personal Browser History Manager

📋 Product Introduction

BrowseBuddy is an enhanced browser extension for history management that provides professional-grade features while prioritizing user privacy. All data is processed locally and never uploaded to any cloud server.

🔐 Core Privacy Promise

  • All data is stored only on your device
  • No data is uploaded to cloud servers
  • No browsing history is shared with third parties
  • Open source code for transparency

✨ Key Features

🗑️

Smart Delete

Bulk delete history by date, domain, or keyword with preview confirmation

📊

Statistics

Visualize browsing habits including top sites and time distribution

🛡️

Privacy Protection

Smart blacklist automatically removes history from sensitive websites

🔑 Permissions

BrowseBuddy requires the following permissions to function. We follow the principle of least privilege, requesting only what is necessary:

Permission Purpose Required
history Read, manage, and delete browser history. Core functionality of the extension. ✅ Required
storage Store extension settings, blacklist data, and user preferences locally. ✅ Required
tabs Get current tab information for the "Add current page to blacklist" feature. ✅ Required
activeTab Get temporary permission for the currently active tab. ✅ Required
<all_urls> Monitor URL changes on all websites for real-time blacklist protection. ✅ Required
contextMenus Add right-click menu items for quick blacklist addition. Optional

⚠️ About the <all_urls> Permission

This permission is only used to monitor URL changes for automatic blacklist deletion. We do not:

  • Collect or upload any browsing data
  • Modify webpage content
  • Send requests to third parties

All URL detection and blacklist matching happens locally. Matched entries are immediately deleted from history without storing any visit information.

📜 Privacy Policy

Data Collection

BrowseBuddy does not collect any personal data. All features run locally, including but not limited to:

  • History record analysis
  • Blacklist matching
  • Statistics generation
  • User settings storage

Data Storage

All data is stored using browser-provided local storage APIs (chrome.storage.local):

  • Extension settings: Stored in browser local storage
  • Blacklist data: Stored in browser local storage
  • Exported files: Saved to user-selected location

Data Sharing

We do not share any data with third parties because we have no access to your data.
