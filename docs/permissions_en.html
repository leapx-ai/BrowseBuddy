Permissions

Detailed explanation of each permission BrowseBuddy uses, its purpose, and necessity

Principle of Least Privilege: We only request the minimum permissions necessary for functionality. Each permission has a specific single purpose and is not used for other purposes.

Required Permissions

The following permissions are essential for BrowseBuddy's core functionality:

history Required

Purpose

Read, search, and delete browser history. This is required for BrowseBuddy's core functionality.

Use Cases

  • Display history list for user viewing and management
  • Search history by date, domain, or keyword
  • Delete specific history entries selected by user
  • Automatically delete sensitive website history after blacklist match

Code Example

// Read history records chrome.history.search({text: '', maxResults: 100}) // Delete specific URL chrome.history.deleteUrl({url: 'https://example.com'}) // Delete date range chrome.history.deleteRange({startTime: Date.now() - 86400000, endTime: Date.now()})
Note: This permission allows access to complete browsing history. We only use this data to display to you and do not upload or share it.
storage Required

Purpose

Store extension configuration, blacklist data, and user preferences locally.

Stored Data

Data Type Purpose Storage Location
User Settings Language, theme preferences chrome.storage.local
Blacklist User-added privacy protection domains chrome.storage.local
Favorited Domains Protected domains excluded from deletion chrome.storage.local
Dwell Time Accumulated time per site (for statistics) chrome.storage.local
Backup Data Auto/manual backup snapshots chrome.storage.local
Data Isolation: Using chrome.storage.local ensures data is saved locally only and not automatically synced to Google accounts.
tabs Required

Purpose

Read tab URLs for the "Add current page to blacklist" shortcut feature and real-time blacklist protection.

Use Cases

  • Get URL of currently active tab
  • Extract main domain displayed on "Add Current Page" button
  • Check if current page is already in blacklist
  • Listen for tab URL changes and auto-delete history when matching the blacklist

Code Example

// Get current active tab const tabs = await chrome.tabs.query({active: true, currentWindow: true}); const currentUrl = tabs[0]?.url; // Real-time protection: listen for URL changes chrome.tabs.onUpdated.addListener((tabId, changeInfo, tab) => { if (changeInfo.url && isUrlBlacklisted(tab.url, blacklist)) { chrome.history.deleteUrl({url: tab.url}); } });

Security Guarantees

  • Only reads URL, not page content
  • Deletes immediately after match, no visit information stored
  • All processing done locally, no network transmission
sessions Required

Purpose

Restore recently closed tabs or windows. Data stays in the local browser; no network transmission involved.

alarms Required

Purpose

Run scheduled background tasks, including auto-backup, auto-cleanup of expired history, and periodic dwell-time snapshots.

Use Cases

  • Automatically create data backups at user-configured intervals
  • Daily auto-cleanup of history older than the retention period
  • Per-minute snapshots of active tab dwell time to survive service worker restarts

Optional Permissions

contextMenus Optional

Purpose

Add "Add to BrowseBuddy Blacklist" option to browser context menu for more convenient addition.

Note: This permission is optional. Even without granting it, you can still manually add domains through the extension popup.

Permissions We Will Never Request

To clarify boundaries, here are permissions BrowseBuddy will never request:

Permission Reason
cookies No need to access or modify cookies
bookmarks Does not manage bookmarks
downloads Only user-initiated exports (not automatic downloads)
notifications Does not use system notifications
webRequest No need to intercept network requests
webNavigation tabs permission already satisfies navigation monitoring needs
