🔑 权限详解

详细说明 BrowseBuddy 每个权限的用途、使用方式和必要性

最小权限原则：我们只请求功能必需的最少权限。每个权限都有明确的单一用途，不会用于其他目的。

必需权限

以下权限是 BrowseBuddy 核心功能所必需的，缺一不可：

history 必需

用途说明

读取、搜索和删除浏览器历史记录。这是 BrowseBuddy 的核心功能所需。

使用场景

  • 显示历史记录列表供用户查看和管理
  • 按日期、域名、关键词搜索历史记录
  • 删除用户选择的特定历史条目
  • 黑名单匹配后自动删除敏感网站历史

代码示例

// 读取历史记录 chrome.history.search({text: '', maxResults: 100}) // 删除特定URL chrome.history.deleteUrl({url: 'https://example.com'}) // 删除日期范围 chrome.history.deleteRange({startTime: Date.now() - 86400000, endTime: Date.now()})
注意：此权限允许访问完整的浏览历史。我们仅将数据用于显示给用户，不会上传或分享。
storage 必需

用途说明

本地存储插件配置、黑名单数据和用户偏好设置。

存储内容

数据类型 用途 存储位置
用户设置 语言、主题等偏好 chrome.storage.local
黑名单 用户添加的隐私保护域名 chrome.storage.local
缓存统计 历史记录统计缓存（可重建） chrome.storage.local
数据隔离：使用 chrome.storage.local 确保数据仅保存在本地，不会自动同步到 Google 账户。
tabs 必需

用途说明

读取标签页 URL，用于"添加当前页面到黑名单"快捷功能以及黑名单实时保护。

使用场景

  • 获取当前活动标签页的 URL
  • 提取主域名显示在"添加当前页面"按钮上
  • 检查当前页面是否已在黑名单中
  • 监听标签页 URL 变更，匹配黑名单时自动删除对应历史记录

代码示例

// 获取当前活动标签页 const tabs = await chrome.tabs.query({active: true, currentWindow: true}); const currentUrl = tabs[0]?.url; // 实时保护：监听 URL 变更 chrome.tabs.onUpdated.addListener((tabId, changeInfo, tab) => { if (changeInfo.url && isUrlBlacklisted(tab.url, blacklist)) { chrome.history.deleteUrl({url: tab.url}); } });

安全保障

  • 仅读取 URL，不读取页面内容
  • 匹配后立即删除，不存储访问信息
  • 所有处理在本地完成，无网络传输
sessions 必需

用途说明

恢复最近关闭的标签页或窗口。数据仅保存在本地浏览器，不涉及任何网络传输。

可选权限

contextMenus 可选

用途说明

在浏览器右键菜单中添加"添加到 BrowseBuddy 黑名单"选项，提供更便捷的添加方式。

使用场景

  • 在网页上右键点击，选择添加到黑名单
  • 在链接上右键点击，添加链接域名到黑名单
提示：此权限是可选的，即使不授予，您仍可通过扩展弹窗手动添加域名。

我们不会请求的权限

为明确边界，以下是 BrowseBuddy 绝对不会请求的权限：

权限 原因
cookies 不需要访问或修改 Cookie
bookmarks 不管理书签
downloads 不自动下载文件（仅用户主动导出）
notifications 不使用系统通知
webRequest 不需要拦截网络请求
webNavigation tabs 权限已满足导航监控需求
